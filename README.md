# 🖥️ WALLACY.OS v5.0 — Zsh Neural Workstation & Cyberpunk Portfolio

An interactive, bilingual (EN / PT-BR) Unix/Zsh workstation and cyberpunk terminal portfolio built with HTML5, Tailwind CSS, Web Audio API, and vanilla JavaScript, showcasing my career as a **Senior Full-Stack & AI Engineer, Tech Lead, and Solutions Architect**.

🔗 **Live Demo:** [https://wallacybr.github.io](https://wallacybr.github.io)

## ⚡ Key Workstation Capabilities

- **Virtual File System (VFS):** Navigate real directories (`~`, `~/projects`, `~/architecture`) using `ls -la`, `cd`, `pwd`, `cat <file>`, and `tree`.
- **Live Cluster Telemetry (`htop`):** Real-time updating ASCII dashboard displaying CPU/GPU/RAM bars and active production processes (`milvus-vector-db`, `facesec_worker.py`, `omnitrak-worker.js`, `sgo-pmesp`).
- **Powerlevel10k Zsh Prompt & `tmux` Status Bar:** Dynamic directory indicators, Git branch state (` main [✓]`), live clock, and simulated cluster latency.
- **Ghost Autocomplete & Shell History:** Inline ghost text suggestions (accept with `Tab` or `→`), command history (`↑` / `↓`), and instant typing skip (`Enter`).
- **Career Git History & Network Tools:** Inspect career milestones with `git log`, test latency with `ping muralha`, or fetch a JSON profile payload via `curl status`.
- **Printable Executive Resume (`cv`):** One-click or command-line compilation of a clean, print-ready PDF resume in English or Portuguese.
- **Multi-Theme Engine (`theme`):** Switch live between `cyberpunk`, `matrix`, `amber`, and `dracula` CRT palettes.
- **Web Audio Synthesizer:** Subtle procedural mechanical key ticks, boot beep, and glitch audio effects with one-click Mute (`🔊 SFX`).
